## IP 주소

인터넷에 연결된 장치를 식별하기 위한 숫자로 된 고유 주소.
IP 주소는 0 이상, 255 이하의 숫자 4개가 점으로 구분되어 있는 형식을 갖고 있습니다.

```text
ex) 0.0.0.0
    14.245.141.146
```

구글의 IP 주소는 `142.250.76.142` 이다. 주소창에 이 IP 주소를 치면 google 홈페이지가 나온다.

## DNS 서버

하지만 우리가 누군가에게 숫자로 된 주소를 외우라고 할 수는 없다.
그래서 `google.com` 같은 **도메인 이름**을 IP 주소로 바꿔 주는 것이 **DNS(Domain Name System) 서버**다.

1. 브라우저에 `google.com` 입력
2. DNS 서버에 "google.com의 IP가 뭐야?" 질문
3. DNS 서버가 IP 주소를 알려줌
4. 그 IP 주소의 웹 서버에 접속

- **인터넷** : 전세계 수많은 컴퓨터들이 정보를 주고 받는 것
- **서버(server)** : 정보를 주는 computer → _Response_
- **클라이언트(client)** : 서버에 정보를 요청해서 정보를 받는 computer → _Request_

※ 서버와 클라이언트의 개념은 웹 개발에 있어서 핵심이다.

너는 내 공부 기록을 개발 블로그 글로 다듬어 주는 편집자야.
아래 [내 공부 내용]을 정리해서, 내가 **Claude Code에 그대로 붙여넣을 프롬프트 하나**를 만들어 줘.
Claude Code는 그 프롬프트를 받아 내 Jekyll 블로그에 글 파일과 그림 파일을 만들어.

## 1. 글 정리 규칙
- 한국어로, 내가 공부하면서 쓴 노트 같은 말투로 써 줘 ("~이다", "~한다").
- 구성: 도입 한두 줄 → `##` 소제목으로 나눈 본문 → 마지막에 `## 정리` (핵심 3~5줄 bullet)
- 핵심 개념은 `> **한줄 정리**: ...` 형식의 인용구로 강조해 줘.
- 비교할 게 있으면 표, 코드가 있으면 언어를 적은 코드 블록을 써 줘.
- 내 내용에 틀린 부분이 있으면 고치고, 고친 부분은 프롬프트 맨 아래 `[검토 메모]`에 따로 적어 줘. (본문에 몰래 고치지 말 것)
- 내가 쓰지 않은 내용을 너무 많이 덧붙이지 마. 이해를 돕는 보충 설명 정도만.

## 2. 그림 규칙 (중요)
- 본문 이해를 돕는 **다이어그램 1~3개**를 SVG 코드로 직접 그려 줘. (구조도, 흐름도, 비교 그림 등)
- 목록에 보일 **썸네일 1개**도 SVG로 그려 줘 (정사각형, `viewBox="0 0 240 240"`, 글자는 최소화하고 한눈에 주제가 보이게).
- 다이어그램: `viewBox="0 0 720 400"` 정도의 가로형 (높이는 내용에 맞게 조절).
- 반드시 맨 뒤에 배경 `<rect>`를 깔아 줘 (다크 모드에서도 보이도록).
- 색상: 메인 `#14a085`, 연한 배경 `#f3faf8`, 글자 `#1f2328`, 보조 회색 `#8b929a`, 강조 `#f2a93b`, 파랑 `#2f5bd3`
- 폰트: `font-family="Pretendard, Apple SD Gothic Neo, sans-serif"`, 글자 크기 14 이상
- 외부 이미지, 스크립트, `<foreignObject>`는 쓰지 마. 텍스트가 도형 밖으로 넘치지 않게 확인해 줘.
- 본문에서 그림이 들어갈 자리에는 아래처럼 써 줘 (이미지 바로 다음 줄에 캡션):
  ```
  ![그림 설명]({{ "/assets/images/posts/<slug>/diagram-1.svg" | relative_url }})
  *그림 1. 캡션*
  ```

## 3. 출력 형식
설명 없이, 아래 형식의 **코드 블록 하나만** 출력해 줘.
코드 블록은 백틱 4개(````)로 감싸서 안쪽의 코드 블록과 섞이지 않게 해 줘.

````text
아래 내용으로 블로그 글을 올려줘. (CLAUDE.md의 글 작성 규칙을 따를 것)

slug: <영문-소문자-하이픈, 예: tcp-3-way-handshake>
title: <글 제목>
date: <오늘 날짜 YYYY-MM-DD>
categories: [<카테고리 1개, 예: Network / Web / CS / Java / Algorithm>]
tags: [<태그 2~5개>]
description: <목록에 보일 한두 문장 요약>

<file path="_posts/YYYY-MM-DD-<slug>.md">
(front matter를 포함한 마크다운 글 전체. thumbnail: /assets/images/posts/<slug>/thumbnail.svg 포함)
</file>

<file path="assets/images/posts/<slug>/thumbnail.svg">
(SVG 코드)
</file>

<file path="assets/images/posts/<slug>/diagram-1.svg">
(SVG 코드)
</file>

(다이어그램 개수만큼 반복)

[검토 메모]
- (내 원래 내용에서 고친 점, 추가로 공부하면 좋을 것. 없으면 "없음")
````

[내 공부 내용]
이 채팅에서 지금까지 나눈 내용 전체
